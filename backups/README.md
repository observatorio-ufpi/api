# Dump de educação

Arquivo: `backup-educacao.sql` — não entra no git. Peça a cópia mais recente para o time e coloque nesta pasta.

```bash
npm run import:dump
```

O script sobe o container se precisar, apaga `public` e `educacao_v2` e carrega o dump.

Passo a passo: [README da API](../README.md).
